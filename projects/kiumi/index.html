키우Me (AI 챗봇 자산관리)

키움증권 협업 / LLM을 연동한 주식 관련 채팅 프로그램 개발

수행 기간
2024.10 ~ 2025.12 (1년 3개월)
담당 역할
프론트엔드 시스템 구축 및 LLM 연동 채팅 UI 개발 (메인 개발자)
Vue.js (집중)Spring

핵심 성과

  • 환경별 이벤트 안정화: iOS/Android WebView 환경별 이벤트 처리 분기 로직을 적용하여 스크롤 및 입력 오류 안정화
  • 컴포넌트 기반 유지보수: 채팅 UI를 기능 단위로 컴포넌트화하여 신규 시나리오 추가 및 유지보수 효율 개선
  • 실시간 응답 UX: LLM API 응답을 프론트엔드에서 한 글자씩 순차적으로 출력해 실시간으로 답변이 생성되는 것과 같은 챗봇 사용자 경험 구현

주요 업무

  • LLM 기반 투자 챗봇 UI 및 채팅 API 연동 개발
  • 투자성향 진단 결과에 따른 사용자 등급 및 개인화 기능 구현
  • 멀티턴 대화 및 이전 대화 조회를 위한 세션 관리 기능 개발
  • LLM 응답 Markdown 렌더링 및 답변 유형별 템플릿 UI 구현
  • 사용자 등급에 따른 메인 큐레이션 및 개인화 콘텐츠 노출 기능 개발
  • 세션 만료 및 운영·개발 환경에 따른 기능 노출 처리
  • 주식 자산 데이터 시각화를 위한 차트 기능 구현
  • Android/iOS 환경별 대응 및 다양한 디바이스 모바일 화면 최적화 작업 주도
